# .claude/skills/: project skills

One folder per skill with a `SKILL.md`. Claude Code loads them from here; other agents can read and follow them. `README.md` is the index, generated by `node scripts/skills-index.mjs` (the post-edit hook runs it).

## Writing or changing a skill
- Use the **skill-creator** skill. Keep `SKILL.md` under 500 lines; move detail to files beside it.
- Frontmatter: `name` (same as the folder), `description` (what it does and exactly when to use it), plus `paths:` to scope it to folders, `disable-model-invocation: true` for skills only a person should start, `argument-hint` when it takes input.
- One skill, one kind of work. Point to the documents instead of copying rules or figures into the skill; copied figures go stale.
- Skills that need deep reasoning say so: "if the session is not on a top-tier model, suggest `/model opus` first".
- Questions to the user: one at a time, recommended option first (the **grilling** style).
- A skill copied or adapted from outside keeps its `LICENSE.txt` and a `SOURCE.md` (where it came from, the commit, what changed). `impeccable` is managed by `skills-lock.json`; don't edit it.

## Checks
- `node scripts/audit.mjs --only=skills,skills-index`.
