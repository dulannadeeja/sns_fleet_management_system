# addenda/: agreed changes to the proposal

- One addendum per agreed change request: `ADD-NNN-short-name.md`, naming its CR, who agreed, the price, phase and timeline effect, and "everything else in the proposal stands as approved".
- Add every addendum to the table in `README.md` in the same commit.
- An addendum is never edited after it is issued; a later change gets a new change request.

## Checks
- `node scripts/audit.mjs`.
